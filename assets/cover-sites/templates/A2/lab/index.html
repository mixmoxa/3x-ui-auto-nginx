INTERPRETATION

One calculation does not define an incident

This calculator intentionally excludes partial requests, retries, different user cohorts and rolling burn-rate alerting. Decide which requests count before placing numbers into a reliability objective. Production SLO measurements should be calculated from trusted metrics, not from a browser demonstration.
