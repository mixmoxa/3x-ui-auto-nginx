What this reference covers

These notes explain common HTTP behaviour using examples grounded in documented standards. They are written for readers inspecting web traffic, building a static site or debugging a reverse proxy.

The examples are illustrative requests, not functioning endpoints on this domain. No sign-in, tracking, simulated API or download is required to read them.
