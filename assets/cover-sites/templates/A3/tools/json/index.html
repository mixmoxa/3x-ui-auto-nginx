What the formatter does

The parser uses the browser built-in JSON.parse. The formatter uses JSON.stringify, which prints a valid JSON value with consistent indentation or compact spacing.

This process does not preserve original whitespace or the textual spelling of some numbers. Very large numeric values follow JavaScript number rules. Use a specialized parser when byte-for-byte preservation matters.
