PROCESS / HOW WE WORK

Start with what people need to do.

A simple method for making design decisions traceable and easy to revise.

01 / DISCOVER

Observe the problem

State the intended audience, the important questions and the surrounding constraints. Collect examples of the content before deciding on a visual direction. A false premise produces polished but unhelpful work.

02 / STRUCTURE

Build a limited system

Choose a small set of layout primitives, scale rules and typographic roles. Test them with inconvenient content: long titles, short labels, empty sections and difficult screen sizes.

03 / TEST

Test and refine

Examine legibility, interaction states and keyboard navigation where relevant. Ask whether a visitor can identify the next useful action without being told where to click.

04 / HANDOVER

Document the decisions

Write down the assumptions, rules and known limitations. This helps a future editor or developer adapt the design without having to rediscover its logic.
