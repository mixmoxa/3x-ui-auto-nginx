NOTES / ORIGINAL STUDIES

An accessibility review is a sequence of checks.

A layout can look quiet and still be difficult to use when a visitor cannot follow its interaction order.

Editorial team · {{DATE_3}}

01 / STUDIO NOTE

Start without a mouse

Tab through every interactive control and confirm that focus is visible. The order should follow the reading sequence rather than jump between decorative regions. A link should lead to a location, while a button should perform an action. If a disclosure menu is present, verify that keyboard users can open and close it. A control that is visually prominent but not reachable from the keyboard is not a complete interface.

02 / STUDIO NOTE

Read the page outline

Use one clear h1 to identify the page and organize supporting sections under meaningful h2 headings. Headings are navigation landmarks for many assistive technology users, not merely convenient font sizes. Avoid skipping levels just to produce smaller text. Image alternatives should describe useful information or mark purely decorative graphics as such. Test whether the content order makes sense without the visual grid.

03 / STUDIO NOTE

Test contrast in context

A colour pair that passes a contrast formula can still become hard to read when text overlays a photograph or a semi-transparent layer. Check the computed colours in each state, including focus, hover and disabled controls. Distinguish ordinary text from large display text when evaluating thresholds. Do not use colour alone to identify an error or current location. Clear words and placement should carry that information as well.

04 / STUDIO NOTE

Separate audit results from assumptions

Automated tools can catch missing labels and certain contrast problems, but they cannot decide whether instructions are understandable. Use manual keyboard checks and, before real deployment, observation with people who use different access methods. Record findings as observed, unresolved or not tested. These notes describe a proposed review method for self-initiated design studies; they do not claim certification or results from external participants.

Related work

Continue with the notes index, or explore the overview for the wider context. Apply the question to an original sketch or a small piece of sample content. Check reading order with a keyboard and a narrow viewport before making claims about usability. These conceptual studies present design reasoning, not commissioned work or validated visitor results.
