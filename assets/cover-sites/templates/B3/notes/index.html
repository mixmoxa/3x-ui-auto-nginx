NOTES / PRACTICE

Ideas from the studio table.

Good design work often benefits from returning to the same basic questions.

01 / CONTENT

Make the content visible first

Start with the actual copy, not lorem ipsum. Placeholder text disguises how real names, long explanations and variable content affect the layout. The visual system should absorb ordinary messiness.

02 / CONTRAST

Use contrast for orientation

Contrast is not just a dramatic colour choice. It establishes relative importance and helps people know where to look next. Test labels and body text independently from large headlines.

03 / BEHAVIOUR

Keep interactions honest

A button should perform an action or lead somewhere meaningful. An inactive signup form, fake authentication flow or placeholder link weakens trust more than a restrained static explanation.

04 / RESTRAINT

Fewer effects, clearer purpose

Animation may demonstrate a spatial relationship, but it should not be required to understand a page. Treat reduced-motion preferences and mobile performance as first-class constraints.
