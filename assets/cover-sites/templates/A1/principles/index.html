PRINCIPLES

Good tools make fewer promises.

Clear structure, predictable behaviour and honest explanations are more useful than complexity for its own sake.

01

Be explicit about where data lives.

The interactive demo on this website operates inside the browser. It may remember tasks using local storage on the current device, but it does not provide accounts, shared workspaces or server synchronization.

02

Prefer a clear next action.

Each task should identify an outcome that can be checked. This makes status easier to understand and reduces the need for extra reporting layers.

03

Keep information easy to find.

Documentation belongs near the decision it explains. Navigation should help people discover real content rather than promise sections that do not exist.

04

Respect a visitor's device.

The pages rely on local styles, illustrations and a small script for the optional demo. No account, external fonts, analytics or third-party scripts are required to use this website.
