GUIDES

A practical start, in four steps.

A short reference for organising everyday work without elaborate systems.

On this page1. Write the scope2. Pick visible steps3. Record decisions4. Review and refineUsing the demo
STEP 01

Write the scope in ordinary language.

Start with two sentences: what are we trying to improve, and how will we know we have succeeded? Avoid beginning with software features or a complete list of requirements. A clear purpose gives later decisions somewhere to belong.

Example

Improve the public documentation so a new reader can find setup instructions and understand the next step without asking for help.

STEP 02

Choose steps that can become complete.

Replace broad tasks such as “improve documentation” with outcomes like “publish an installation guide” or “check five common links”. If an item cannot be reviewed, it is probably too large.

A short task list is easier to maintain than a large backlog of vague intentions.

STEP 03

Keep the reason beside the decision.

When you choose an approach, write down the constraints that mattered. Later reviewers need to understand why the choice was appropriate, not simply which option was selected.

Link relevant references and state what would cause the decision to change.

STEP 04

Review what changed.

Look for completed work, newly discovered constraints and tasks that should be removed. A good review shortens the next action list rather than expanding it by default.

BROWSER DEMO

How this demonstration works.

The workspace demo starts with sample tasks. Add your own text, use the checkboxes, remove an item or restore the examples. Changes are saved using local browser storage when available.

It is intentionally not a collaboration service. There is no shared account, cloud synchronization, authentication or remote storage.
