**3X-UI AUTO NGINX** устанавливает [3x-ui](https://github.com/MHSanaei/3x-ui) и Xray, настраивает nginx, HTTPS, подключения, подписки, диагностику и Backup / Restore. Через интерактивное меню можно менять домены и управлять резервными копиями. AmneziaWG 3.1 и AdGuard Home с DoH — по желанию.

Нужны два домена и чистый VPS. Сайт-прикрытие установщик выбирает и разворачивает автоматически.

## 🚀 Быстрый старт

Настройте DNS-записи **двух доменов**, указав IP-адрес вашего VPS: один для панели, другой для REALITY. Подключитесь по SSH под **root** и разрешите входящие TCP **80/443** и UDP **443**. [Поддерживаемые ОС](#technical-details).

```bash
curl -fSL https://github.com/xPROMSx/3x-ui-auto-nginx/releases/latest/download/x-ui-latest.sh -o x-ui-latest.sh && bash x-ui-latest.sh
```

После запуска выберите **1 — English** или **2 — Русский**. Затем откроется главное меню:

- **1 — Установка:** настройка сервера с нуля или полная переустановка.
- **2 — Смена доменов:** изменение домена панели, REALITY или обоих без переустановки.
- **3 — Резервные копии:** создание, просмотр и восстановление Backup.
- **0 — Выход.**

Для работы с меню нужен интерактивный SSH-терминал.

<details>
<summary><strong>Резервная загрузка — если GitHub Releases недоступен</strong></summary>

Установка напрямую из актуальной ветки `main`. Её содержимое может отличаться от последнего опубликованного релиза.

```bash
curl -fSL https://raw.githubusercontent.com/xPROMSx/3x-ui-auto-nginx/main/x-ui-latest.sh -o x-ui-latest.sh && bash x-ui-latest.sh
```

</details>

<a id="installation-vs-update"></a>

> [!CAUTION]
> **Установка — не обновление!**
>
> Повторный запуск скрипта **без параметров** открывает менеджер, а не переустанавливает сервер. Но пункт **«Установка»** предназначен для чистого VPS или полной переустановки.
>
> Если обнаружена существующая установка, скрипт предупредит об удалении управляемых данных и запросит точное подтверждение **YES**. При переустановке заменяются база 3X-UI и конфигурация nginx. **Заранее сохраните Backup вне VPS.**
>
> **«Смена доменов»** и **«Резервные копии»** — отдельные операции, не требующие переустановки панели.

<details>
<summary><strong>Как обновляться?</strong></summary>

- **3X-UI и Xray:** используйте штатные средства панели. Совместимость новых версий с конфигурацией проекта может быть ещё не проверена.
- **3X-UI AUTO NGINX:** обновление установленного стека поверх существующего не поддерживается. Для доступа к возможностям нового менеджера можно скачать актуальный скрипт и выбрать нужную операцию — он проверит совместимость установленной конфигурации.
- **Backup / Restore:** сохраняет и восстанавливает данные, но не обновляет стек.

**Не выбирайте «Установка» ради обновления!** nginx, ядро Linux и другие системные пакеты обновляются средствами ОС.

</details>

Ниже описаны настройки, которые предлагает установщик при выборе пункта **«Установка»**.

<a id="3--enhanced-vps-security"></a>

### 3. 🔐 Расширенная безопасность VPS

> `Усилить безопасность VPS? [Y/n]:`

*Рекомендуется неопытным пользователям · Включена по умолчанию (`Y`)*

Установщик настроит Fail2ban для защиты SSH, зашифрованный системный DNS (DoT) и автоматические обновления безопасности. При подходящих условиях также создаётся swap-файл размером 1 ГиБ — независимо от выбора дополнительной защиты.

**Перед включением ознакомьтесь с параметрами ниже**, особенно с расписанием автоматических перезагрузок.

<details>
<summary>🔐 <strong>Подробное описание настроек безопасности</strong></summary>

Дополнительная защита включается при выборе `Y`. Подготовка swap выполняется независимо от этого выбора:

- **Swap 1 ГиБ.** Если swap отсутствует, файловая система поддерживается и свободно не менее 4 ГиБ, установщик создаст и активирует swap-файл. Существующие настройки swap не изменяются. Если условия не выполнены, этот этап будет пропущен без остановки установки.
- **Защита SSH — Fail2ban.** Ограничение повторных неудачных попыток входа с учётом фактических SSH-портов. Существующие параметры SSH-аутентификации не изменяются.
- **Шифрованный DNS (DoT).** Глобальные DNS-серверы Cloudflare и Google используют строгий DNS-over-TLS через `systemd-resolved`. DNS-маршруты и search domains интерфейсов/VPN сохраняются; их запросы могут оставаться незашифрованными. Если подготовка DoT не удалась, но исходный DNS успешно восстановлен, установка основного стека, Fail2ban и автоматических обновлений продолжается независимо от DoT; итоговый статус сообщает об отказе, код завершения ненулевой.
- **Автоматические обновления безопасности.** Обновление списков пакетов — в 02:30, установка обновлений — в 02:50.
- **Автоматическая перезагрузка — 04:38.** Если после обновлений системе потребуется перезагрузка, она выполняется в указанное время, **в том числе при активных пользовательских сеансах**. Это может прервать действующие подключения.

Время указано по локальному часовому поясу VPS.

Перед изменениями выполняются проверки совместимости существующих настроек. При ошибках конфигурации безопасности предусмотрен контролируемый откат.

**Важно:** установщик не отключает SSH-вход по паролю и не заменяет полноценное администрирование сервера. Рекомендуется настроить вход по SSH-ключам и затем самостоятельно отключить парольную аутентификацию.

</details>

> `Настроить дополнительное подключение VLESS TCP/TLS (XTLS Vision)? Нужен отдельный домен. [y/N]:`

*Дополнительное подключение · По умолчанию отключено (`N`)*

Альтернативное VLESS-подключение с TLS, которое может быть полезно, если REALITY работает нестабильно или блокируется в вашей сети. Устанавливается как отдельный профиль в панели 3X-UI.

> [!IMPORTANT]
> **Для XTLS Vision требуется третий домен**, отличный от доменов панели и REALITY. Его DNS-запись должна указывать на IP-адрес VPS. HTTPS-сертификат и маршрутизация nginx настраиваются автоматически.
>
> После выбора `Y` установщик дополнительно запросит домен: `Введите домен VLESS TLS Vision (отличный от доменов панели и REALITY):`.

### 6. 🛡️ AdGuard Home + DNS-over-HTTPS

> `Установить и настроить AdGuard Home? [y/N]:`

*Дополнительный DNS-сервер · По умолчанию отключён (`N`)*

Персональный DNS-сервер с блокировкой рекламы и отслеживания, управлением клиентами и защищёнными DNS-запросами.

<details>
<summary>ℹ️ <strong>Подробнее об AdGuard Home и настройке доступа</strong></summary>

Дополнительный домен не требуется.

После установки будут доступны:

- **Панель AdGuard Home:** `https://panel.example.com/adg-.../` — индивидуальный случайный путь.
- **DNS-over-HTTPS:** `https://panel.example.com/dns-query`.

Публичные TCP/UDP-порты **53** не открываются. Конфигурация и данные AdGuard Home сохраняются в **Backup / Restore v3**.

**⚠️ Рекомендация по безопасности**

Для личного VPS рекомендуется использовать отдельный [ClientID](https://adguard-dns.io/kb/ru/adguard-home/clients/#clientid) для каждого устройства.

В интерфейсе AdGuard Home откройте **Настройки → Настройки DNS → Настройки доступа → Разрешённые клиенты** и укажите только созданные ClientID, без IP-адресов и подсетей.

Используйте DoH-адреса вида:

`https://panel.example.com/dns-query/<ClientID>`

После настройки запросы без разрешённого ClientID, в том числе на обычный `/dns-query`, будут отклоняться.

Используйте длинные случайные идентификаторы. Подробнее — в [официальных рекомендациях AdGuard Home](https://adguard-dns.io/kb/ru/adguard-home/running-securely/).

</details>

<a id="change-domains"></a>

## 🌐 Смена доменов

В главном меню выберите **2 — Смена доменов**. Можно заменить домен панели, REALITY или оба сразу без переустановки. Новые DNS-записи должны указывать на VPS; для получения сертификатов необходим доступ к TCP/80. Домены должны различаться между собой и с доменом Vision.

Перед изменениями автоматически создаётся полный Backup v3. Клиенты, ключи, настройки и статистика сохраняются. Домен Vision не меняется. После успешной смены может потребоваться обновить адреса подписок и настройки клиентов.

Поддерживаются только распознанные конфигурации проекта, включая совместимые установки v2.1.7. При ошибке **не удаляйте Backup и данные восстановления**. Если появилось `ROLLBACK_UNVERIFIED`, остановитесь и сохраните диагностику. [Подробности, ограничения и восстановление](docs/MANAGER.md#change-domains).

<a id="backup--restore"></a>

## 💾 Backup / Restore

В главном меню откройте **3 — Резервные копии**, чтобы создать Backup, просмотреть список архивов или выполнить Restore. Резервную копию можно использовать после переустановки ОС или для переноса на другой VPS. Для восстановления должны совпадать операционная система, её версия и архитектура процессора.

Для работы через командную строку доступны команды (от root):

```bash
# Создать новую резервную копию
x-ui-backup backup

# Показать доступные копии
x-ui-backup list

# Восстановить выбранную копию
x-ui-backup restore /var/backups/x-ui/<archive>.tar.gz
```

Архивы сохраняются в `/var/backups/x-ui/`.

> **Backup содержит чувствительные данные:** базу клиентов, пароли и приватные ключи сертификатов. Храните копию **вне VPS** и восстанавливайте только доверенные архивы.

Если Restore невозможен, файлы можно аварийно извлечь без установки пакетов и запуска служб. Нужны только Bash, Python 3 и доступ к архиву и месту извлечения; root не требуется:

```bash
x-ui-backup extract /path/to/archive.tar.gz ./recovered-backup
```

Каталог должен быть новым; исходные пути сохраняются под `files/`, ссылки пропускаются. Данные содержат секреты — не копируйте их поверх работающего сервера без проверки.

## 🔐 Безопасность

Служебные интерфейсы не открываются напрямую в интернет: панель, подписки и дополнительные сервисы доступны через nginx и HTTPS, а внутренние порты остаются локальными.


**Не уверены, как самостоятельно защитить VPS?** При установке можно включить расширенную настройку безопасности. Установщик автоматически настроит защиту SSH от перебора паролей, шифрованный DNS и обновления безопасности. Перед включением ознакомьтесь с подробным описанием и расписанием ночных перезагрузок в разделе «Быстрый старт».

**Важно:** не забывайте защищать сам доступ к серверу. Используйте SSH-ключи, а после проверки входа по ключу отключите аутентификацию по паролю. Установщик не отключает её автоматически.

## ⚙️ Технические подробности и совместимость

- **ОС:** Ubuntu 24.04, Ubuntu 26.04 и Debian 13.
- **UFW:** разрешаются 80/tcp, 443/tcp и 443/udp (8443/udp — при выборе AmneziaWG). При установке UFW включается только после проверки SSH-доступа; если сделать это безопасно нельзя, остаётся выключенным с предупреждением. После Restore через меню его можно включить **только по отдельному выбору** и после проверок безопасности; обычная команда `x-ui-backup restore` UFW не включает.
- **Сертификаты:** Let's Encrypt webroot и `certbot.timer` продлевают сертификаты автоматически, без остановки nginx.
- **Версия 3x-ui:** по умолчанию устанавливается последняя версия, тщательно протестированная на совместимость с 3X-UI AUTO NGINX. После установки вы можете самостоятельно обновить 3x-ui штатными средствами панели, но совместимость новой версии с нашей конфигурацией может быть ещё не подтверждена. Другой стабильный релиз можно явно выбрать через `-version <tag>` (минимальная поддерживаемая версия — v3.8.0); установщик предупредит о неподтверждённой совместимости.

### Восстановление на новом VPS

Нужны те же ОС, версия и архитектура, что у копии. При смене IP VPS обновите DNS-записи доменов. Не запускайте `x-ui-latest.sh` — установите только утилиту и восстановите доверенный архив:

```bash
curl -fSL https://raw.githubusercontent.com/xPROMSx/3x-ui-auto-nginx/main/assets/backup/x-ui-backup.sh -o /tmp/x-ui-backup
install -o root -g root -m 0755 /tmp/x-ui-backup /usr/local/bin/x-ui-backup
rm -f /tmp/x-ui-backup
x-ui-backup restore /root/<archive>.tar.gz
```

SSH, настройки ОС и базовый firewall остаются ответственностью администратора. Для архивов v2 нужна утилита из соответствующего старого релиза.

## 🖥️ Флаги стран в Windows 11

Если при открытии панели **3x-ui** в **Chrome, Edge или Brave** на Windows 11 вместо флагов стран отображаются буквенные коды (`FI`, `DE`, `US`), воспользуйтесь нашим небольшим проектом [**Flag Emojis Windows Installer**](https://github.com/xPROMSx/flag-emojis-windows-installer). Он помогает вернуть отображение флагов, сохраняет оригинальный шрифт Windows и имеет возможность отката.
