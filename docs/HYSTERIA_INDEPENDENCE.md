# REALITY, Hysteria2 и XHTTP: независимость и обслуживание

Для новой установки TCP-сайт REALITY остаётся доступным и при выключенном
REALITY inbound. Nginx использует штатный резервный upstream:

```nginx
upstream xray {
    server 127.0.0.1:8443 max_fails=0;
    server 127.0.0.1:9443 backup;
}
```

`max_fails=0` исключает десятисекундный карантин primary после отказа connect.
Следующее соединение снова пробует REALITY; при OFF обычный TLS идёт на 9443.
Сохраняются PROXY protocol и доверие только к необходимому loopback-источнику.
Резерв не ведёт к панели 7443. Старый xver=0 автоматически не меняется.

## Проверка ролей

Fresh Install строго требует исходно включённые REALITY TCP, Hysteria2 UDP
и XHTTP Unix listener с общим владельцем Xray.
`check_installation maintenance` читает enable трёх известных локальных ролей
из SQLite и требует listener только для включённых. Отсутствующая роль,
неизвестная структура, удалённый node или чужой владелец не принимаются.
При всех трёх OFF проверяется наличие управляемого процесса Xray.
Проверка ничего не включает и не меняет базу.

Интеграционный тест использует штатный `setEnable` API 3x-ui и проходит все
восемь сочетаний ON/OFF, включая обратные включения. Проверяются настоящие
REALITY/Hysteria2/XHTTP-клиенты, сохранённые соединения соседей, listeners,
RAW/JSON, клиентские данные, публичный TCP-сайт и HTTP/3 при HY ON.
Перезапуск процессов проверяется отдельно; Full Fresh выключает все три роли
перед настоящей холодной загрузкой и включает их через API после проверки
сохранённых флагов, данных и TCP-сайта.

## Change Domains и Backup v3

Panel only сохраняет REALITY/Hysteria2 домен, TLS и Unix-vhost.
REALITY only меняет также нативный HY Host/SNI, пути REALITY-сертификата
и server_name статического Unix-vhost. Both применяет обе роли.
Отключённые inbound обновляют параметры для будущего включения, сохраняя OFF.
Backup перед переключением, durable journal и scoped rollback остаются прежними.

Строгие проверки распознают новый согласованный layout целиком: upstream,
Unix-vhost и его activation link, HY masquerade/TLS и REALITY xver=1.
Неизвестные изменения отклоняются. Прежний поддерживаемый Panel/HY layout
сохраняется без миграции; исходный strict runtime остаётся неизменным также
для распознавания исторических deploy hooks.

Backup v3 сохраняет существующие деревья, сайты, сертификаты, клиентов,
`cover-sites.json` и enable-флаги. Формат и TREE_PATHS не меняются.
Сокет в /run не архивируется: его пересоздаёт Nginx после Restore/старта.
Root fixtures проверяют безопасный отказ, сохранность и rollback; полное
восстановление настоящих служб и клиентов проверяет существующий Full Fresh.

## Продление сертификатов

Hysteria2 ссылается на REALITY lineage с `oneTimeLoading=false`.
Xray по умолчанию перечитывает сертификат раз в 3600 секунд; мгновенная смена
сертификата не обещается. REALITY deploy hook делает Nginx reload и не
перезапускает Xray. Panel/Vision сохраняют собственный существующий контракт.
Профильная регрессия проверяет новый сертификат при REALITY OFF / HY ON,
сохранённое соединение, PID и флаги. Короткий тест использует тестовый интервал;
отдельный длительный эксперимент проверяет неизменённый часовой интервал.

Установка на production, миграции старых VPS и дополнительный Full Fresh
исследовательских вариантов не выполняются.
